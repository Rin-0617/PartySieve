# PartySieve

FFXIV Dalamud向けのパーティ募集フィルタープラグインです。

パッチ7.57のリージョン内フリーマッチングで日本DC全体の募集が見えるようになり、募集の数が大きく増えました。
PartySieveは、検索妨害のような募集を自動で隠し、条件を組み合わせたフィルターで絞り込み、募集主のホームDCを色で見分けられるようにします。

公式のパーティ募集画面をそのまま使えるように、一覧や詳細検索を拡張する形で動きます。

## 主な機能

- 検索妨害のような募集の自動非表示（同じ文面の連投、記号だらけの募集文、同じ文字の長い連続）
- 「かつ (AND)」「または (OR)」で行を組み合わせるフィルタールール
- 公式の詳細検索の横に、フィルターのパネルを表示
- 公式のパーティ募集一覧と詳細画面で、募集主の名前をホームDCの色で表示
- 表示する募集主のDCの選択
- 判定だけ行い隠さないモード（隠しすぎていないかの確認用）
- 受信ログ（隠した募集とその理由の確認）

## 導入

現在は開発版のみです。

1. ビルドしたファイル（`PartySieve.dll`、`PartySieve.json`、`PartySieve.deps.json`）を任意のフォルダに置きます。
2. `/xlsettings` の試験的機能から、Dev Plugin Locationsに `PartySieve.dll` のパスを追加します。
3. `/xlplugins` でPartySieveを有効にします。

## 使い方

1. いつもどおり公式のパーティ募集を開きます。初期ルールとスパム判定に合う募集は、最初から隠れます。
2. 募集主の名前が、ホームDCの色で表示されます。
3. 公式の「詳細検索」を開くと、右隣にPartySieveのフィルターパネルが出ます。ここでルールの追加や、表示するDCの切り替えができます。
4. 細かい設定は `/psieve` か、Dalamudのプラグイン一覧の設定ボタンから開きます。

ルールやDCの設定を変えたあとは、公式の一覧を更新すると反映されます。受け取り済みの募集をあとから隠すことはできないためです。

## DCの色分け

| DC | 色 | ワールド |
|---|---|---|
| Elemental | 緑 | Aegis, Atomos, Carbuncle, Garuda, Gungnir, Kujata, Tonberry, Typhon |
| Gaia | 金 | Alexander, Bahamut, Durandal, Fenrir, Ifrit, Ridill, Tiamat, Ultima |
| Mana | 紫 | Anima, Asura, Chocobo, Hades, Ixion, Masamune, Pandaemonium, Titan |
| Meteor | 赤 | Belias, Mandragora, Ramuh, Shinryu, Unicorn, Valefor, Yojimbo, Zeromus |

7.57以降、ゲームデータ上では日本の全ワールドがElemental所属として扱われているため、ワールドとDCの対応はプラグイン側の表で判定しています。

同じ名前で別のDCの募集主が同時にいる場合は、どちらか判別できないため色を付けません。

## 表示する募集主のDC

設定の「全般」と、詳細検索の横のパネルにチェックボックスがあります。
初期状態はすべて表示です。チェックを外したDCの募集主の募集が隠れます。

日本以外のワールドの募集主には影響しません。

## フィルタールール

1つのルールは、動作と、1行以上の条件でできています。

動作:

- 条件に合う募集を隠す
- 条件に合う募集だけ残す
- 条件に合う募集は必ず表示（他のルールやスパム判定、DCの選択より優先）

条件の1行は「[対象] [語] [を含む / を含まない]」です。
対象は「すべて」「募集文」「募集主」「コンテンツ名」「募集主のDC」から選べます。

2行目以降は、先頭で「かつ (AND)」か「または (OR)」を選びます。
「かつ」でつながった行がひとまとまりになり、「または」でまとまり同士をつなぎます。

```text
条件         [コンテンツ名] 絶         を含む
かつ (AND)   [募集文]       練習       を含まない
または (OR)  [募集文]       消化       を含む
```

上の例は「（絶 かつ 練習を含まない）または 消化を含む」になります。

全角半角、大文字小文字、カタカナひらがなは区別しません。
条件の種類には「正規表現（上級者向け）」もあります。

## 初期ルール

| ルール | 内容 |
|---|---|
| RMT・外部サイト | RMT、外部URL、「100万gil」のような表記を含む募集を隠します。DiscordとロドストのURLは対象外です |
| 固定募集（Discord・ロドストのURL） | DiscordやロドストのURLを含む募集を隠します。固定を探している場合は、このルールのチェックを外してください |

「VCはDiscord」のような書き方には反応しないので、野良募集は隠れません。
短縮URLは行き先が分からないため、RMT・外部サイトとして扱います。

## スパム判定

設定の「スパム判定」タブで、それぞれのオン/オフとしきい値を変えられます。

- 同じ文面の連投: 一定時間内に、同じ文面を何人もの募集主が出している募集（空白や記号だけ変えたものも同じ文面とみなします）
- 記号だらけの募集文: 記号の割合が一定以上の募集文
- 同じ文字の長い連続: 「ああああああああ」「★★★★★★★★」のような募集文

誤って隠したくない募集は、「必ず表示」のルールで救えます。

## コマンド

```text
/psieve
```

サブコマンド:

- `/psieve on` ルールとスパム判定に合う募集を隠す
- `/psieve off` 判定だけ行い、隠さない

# PartySieve v0.1.0

最初のリリースです。

## 機能

- 検索妨害のような募集を自動で隠します（同じ文面の連投、記号だらけの募集文、同じ文字の長い連続）。
- 「かつ (AND)」「または (OR)」で条件の行を組み合わせるフィルタールールを追加しました。
- 公式の詳細検索の横に、フィルターのパネルを表示します。
- 公式のパーティ募集一覧と詳細画面で、募集主の名前をホームDCの色で表示します（Elemental 緑、Gaia 金、Mana 紫、Meteor 赤）。
- 表示する募集主のDCを選べます。
- 初期ルールとして「RMT・外部サイト」「固定募集（Discord・ロドストのURL）」を用意しました。固定を探している場合は、固定募集のルールのチェックを外してください。
- 判定だけ行い隠さないモードと、隠した募集と理由を確認できる受信ログがあります。
- 設定画面とフィルターパネルのタイトルバーに♡ボタンを追加しました。押すとOFUSEの支援ページ (https://ofuse.me/rin0617) を開きます。
